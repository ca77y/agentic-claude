# Plugin text

- Keep rules minimal, concise, and about the current state only.
- Give each skill or agent only the context its job needs, and state each rule once.
- A description is one sentence that says what the part does and when to use it.
- READMEs are for humans. Never point an instruction at one.
- Follow `docs/ARCHITECTURE.md`. When a change alters a decision in `docs/DESIGN.md`, update it in the same change.
