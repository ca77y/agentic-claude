## Key evidence

- Plotly Python `write_html` writes a figure as an interactive HTML file. (paraphrase of search snippet) ^e1
- The default `include_plotlyjs` setting embeds plotly.js in the file or loads it from a CDN, depending on the value passed. (paraphrase of search snippet; the exact values and default were not read) ^e2

## Limitations

- Search snippets only. The exact `include_plotlyjs` values, the default, and whether the default output is self-contained were not verified.
- Gathered for a benchmark-report question: whether Plotly could produce a per-run static HTML report was not tested.

## Relevance

- A possible way to generate a single-file, interactive HTML chart report from a script that computes the output path per run. Uncertain until the page is fetched.
