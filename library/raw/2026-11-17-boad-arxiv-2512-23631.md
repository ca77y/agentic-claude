# BOAD - Discovering Hierarchical Software Engineering Agents via Bandit Optimization (arXiv 2512.23631)

> [!quote] Source
> **URL**: https://arxiv.org/abs/2512.23631 (abstract page; figures below were read in the full text at https://arxiv.org/html/2512.23631v2)
> **Accessed**: 2026-11-17
> **Method/Context**: Xu et al. Published 2025-12-29 (v1); v2 2026-01-01. Gathered for the question of published evals of a single agent vs an orchestrator with sub-agents. Section and table references are to the v2 HTML. The researcher did not read every line of the paper.

## Key evidence

- **Token use, single agent vs orchestrated, same model and tools (sec 5.2 Token Analysis, Table 2).** Total tokens are the average of input plus output tokens per issue. SWE-bench Verified: SWE-agent 0.92M vs BOAD 0.93M (+0.7%). SWE-bench-Live: 1.49M vs 1.13M (-23.8%). Max input tokens: Verified 34.6k vs 30.5k (-11.6%); Live 49.0k vs 36.7k (-25.0%). This is the only controlled coding eval the researcher found that reports tokens for both arms on one fixed model and tool set. ^e1
  > [!quote]
  > "Surprisingly, the total token count is comparable—and even lower on SWE-bench-live—than in the original SWE-agent. Moreover, BOAD consistently reduces input tokens"

- **Model and tools held fixed (sec 5.1).** The orchestrator and every sub-agent run on Seed-OSS-36B-Instruct at temperature 0.0, with the SWE-agent scaffold and default tools (edit_anthropic, bash, submit). The orchestrator prompt and sub-agent prompts were generated by Claude-4 and tuned on a 12-issue design set, so design and prompts are searched together. Controlled on model and tools, with a prompt-tuning caveat. ^e2
  > [!quote]
  > "both orchestrator and sub-agents use Seed-OSS-36B-Instruct with temperature 0.0"; "This choice ensures improvements reflect the benefit of orchestration rather than fine-tuning"; "Each sub-agent is ... given access to the same default tools as the orchestrator."

- **Success rates (Table 1, Seed-OSS-36B).** SWE-bench Verified / SWE-bench-Live: SWE-agent single agent 49.8 / 12.3; SWE-agent + manual sub-agent 47.4 / 14.0; SWE-agent + evolutionary search 46.0 / 17.0; SWE-agent + BOAD 53.2 / 20.0. The manually designed multi-agent design scored below the single agent on Verified. 53.1 is the Verified score excluding the 12 design-set issues. The Live ablation counts 60/300 (20.0%) for BOAD (Table 3), so Live has 300 issues. The table gives no sample size or significance. ^e3

- **Ablations (sec 5.3, Table 3): coordination design drives the result.** No sub-agents but a tuned prompt: 16.3% on Live. Two sub-agents peak at 60/300 (20.0%). One sub-agent 49/300, three 49/300, four 50/300, five 41/300. A generic orchestrator prompt scores 50/300 (16.7%) vs 60/300 (20.0%) with a customized prompt. ^e4
  > [!quote]
  > Larger teams "reduce performance due to communication and coordination overhead" (authors' wording as recorded by the researcher).

- **Authors' stated limits (Limitations and Future Work).** Only a small open model (36B) was run; evolution on large models is left as future work. ^e5
  > [!quote]
  > "discovered sub-agents transfer across models only partially and failure cases highlight error propagation when orchestrators unconditionally accept sub-agent outputs"

## Limitations

- Cost per run and latency per design are not reported for the single-agent vs orchestrated arms in the text searched (keyword search of the full HTML). The researcher did not read every line.
- The text searched reports no significance test; each result appears to be a single run at temperature 0 (inference, not a quoted statement).
- Prompts were tuned on a 12-issue design set, which includes issues in the Verified evaluation (hence the 53.1 figure excluding them).
- Only a 36B open model was tested; transfer to other models is only partial per the authors.
- Section, table and quotation details come from the researcher's recorded reading of the v2 HTML; this note's source URL is the abstract page.

## Relevance

- Gives a controlled data point on tokens for a single agent vs an orchestrator with sub-agents: total tokens roughly equal on Verified and lower on Live, with lower peak input in both.
- Shows a hand-designed multi-agent setup can underperform a single agent (Verified 47.4 vs 49.8), and that team size and orchestrator prompt matter.
