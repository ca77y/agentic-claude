# Raw notes

Use the raw-note template and only your assigned paths. Record the source identity, dates, supporting passages, the claims they support, and uncertainty, keeping quotation apart from inference. Give each key-evidence bullet one block ID at the end of its line, unique within the note; to point at another block, mention its ID inside the line. Append to an existing note in a dated section; never rewrite it. An unfetched lead carries its URL and the reason, never invented contents.

Write the `summary` from what the body records, no more broadly. Keep the body's hedges: say what the source shows and how you know it, such as "the abstract names" rather than "the paper evaluates" when only the abstract was read, and claim no "only", "none", or "the one" that a search alone supports. The index repeats the summary, so a reader who never opens the note gets exactly that claim.

Use existing taxonomy tags and return proposed new ones separately. Leave index, taxonomy, and log changes to the integrator, and return them as deferred metadata.
