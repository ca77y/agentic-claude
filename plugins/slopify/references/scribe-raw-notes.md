# Raw notes

Use the raw-note template and only your assigned paths. Record the source identity, dates, supporting passages, the claims they support, and uncertainty, keeping quotation apart from inference. Append to an existing note in a dated section; never rewrite it. An unfetched lead carries its URL and the reason, never invented contents.

Use existing taxonomy tags and return proposed new ones separately. Leave index, taxonomy, and log changes to the integrator, and return them as deferred metadata.
