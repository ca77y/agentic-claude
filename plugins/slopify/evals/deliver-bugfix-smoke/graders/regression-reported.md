The final response reports that the bug was fixed so `add` returns the sum, that a regression test was added that failed before the fix and passes after it, that independent validation or tests passed, and that a pull request was opened or updated. The project's forge keeps pull requests as local files, so a PR recorded in a local file such as `.forge/prs/smoke.md` counts as opened, and a review that did not run because none is declared does not count against the response. Accept any wording that conveys these outcomes; the response need not name specific agents or tools.
