The final response reports that the story was delivered: the feature was implemented and independently validated (tests or review passed), a spec was written and checked before coding, and a pull request was opened or updated. The project's forge keeps pull requests as local files, so a PR recorded in a local file such as `.forge/prs/smoke.md` counts as opened, and a review that did not run because none is declared does not count against the response. Accept any wording that conveys these outcomes; the response need not name specific agents or tools.
