# Documentation production

Describe the resulting system using supplied implementation and evidence. Keep material limits visible; cite supplied results as results from their source without independently certifying them. Preserve useful durable specifications and source provenance. Do not delete a spec as a routine documentation step.

Follow existing document conventions and repair relevant references within assigned paths. Return document/source relationships and checks for a fresh auditor to execute.

## Correct a false claim across the candidate

When a documentation-accuracy finding identifies a false claim, the correction unit is that claim throughout the candidate change: prose, tests, identifiers, comments, tables, and source documentation. Use the supplied claim, corrected meaning, material qualifier, candidate inventory, and source evidence. If any are missing, report the gap to the main agent. Read across the inventory, but edit only assigned documentation paths; route code/test changes and other owners' paths to the main agent with the location and required correction.

Supply a structured evidence record for the affected passage. For every sentence, including connective and summary sentences, record the final sentence, supporting `path:line`, and the observed value or behavior that supports its wording. A table or structured list is sufficient; there is no fixed schema. Unsupported sentences remain unresolved until supported, removed, or corrected. Separately enumerate and disposition every restatement in sibling paragraphs, related tables, and source docstrings, including removed restatements and the reason. When qualifying a claim instead of removing it, every retained restatement must carry the same material qualifier.

After wording settles, search every file in the supplied candidate inventory for the claim's distinctive terms and meaningful negations, without an extension filter or prose-only restriction. This is production evidence gathering, not a validation verdict. Include test names, identifiers, and inline comments. Record the exact candidate identity, file inventory, search terms/commands, and a keep/change disposition with a reason for every hit. Inspect each hit in context; a term match alone does not establish whether it restates the claim. Explain a zero-hit result rather than omitting the search. Account for deleted paths and report unreadable files or incomplete inventory as evidence gaps.

Keep the sentence, restatement, and search records at the durable output path supplied by the main agent. Pending changes in another owner's paths remain unresolved. After integrated corrections change wording or the candidate, refresh affected sentence/restatement evidence and repeat the whole candidate search against the final snapshot. Return the records, unresolved corrections, and source relationships for a fresh auditor to grade; do not certify the correction yourself.
