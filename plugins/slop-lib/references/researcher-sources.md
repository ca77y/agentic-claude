# New sources and limitations

Retrieve through the configured provider and retain source identity, retrieval date, version/publication date, and passages supporting each claim. Prefer authoritative sources suited to the question. Capture contradictions and time/version boundaries; distinguish quoted material, paraphrase, and inference.

For failed or thin retrieval, record the query/source, provider, observation, and limitation. An authorized bounded control query through the same provider may diagnose access; it does not support the unanswered subject. Avoid repeating an unproductive path. Unfetched leads retain their URL and reason but no assertions about unseen contents. Return evidence to the main agent without library writes.
